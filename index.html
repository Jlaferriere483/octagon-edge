Sources & imports

Connect multi-promotion data

Fight Forensics offers a free read-only JSON API for fighters, profiles, bouts, events and promotions. Request a key and display the attribution link below. This app calls the provider directly from your browser.

Get free API key / API docs · Fight Forensics data source

Import your own data

CSV fields: name, promotion, wins, losses, draws, age, height_in, reach_in, stance, slpm, str_acc, sapm, str_def, td_avg, td_acc, td_def, sub_avg, recent_form. Leave unknown fields blank. Percentages can be 0–1 or 0–100.

Data integrity

  • Imported profiles are labeled with their source.
  • Same-name fighters are not automatically merged; verify identity before combining records.
  • Promotion coverage and statistical depth vary. Missing values remain unknown.
  • Predictions currently use an explainable baseline, not a trained/validated forecasting model.
  • Profiles and predictions are stored locally on this device, not in a shared cloud database.
