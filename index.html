The app can now search a multi-promotion public-record database and a UFC-focused community source. Coverage and statistics vary by promotion; demo profiles remain illustrative.

Import fighter statistics

CSV headers supported: name, wins, losses, draws, sig_strikes_landed_per_min, sig_strikes_absorbed_per_min, striking_accuracy, striking_defense, takedown_avg_per_15, takedown_accuracy, takedown_defense, submission_avg_per_15, reach_in, age, recent_form. Percent fields can be entered as 0–1 or 0–100.

Historical results

Prediction grading is available from the Predictions tab. This prototype imports fighter profiles on demand. It does not yet automatically sync all fight histories or continuously refresh results; that requires additional integration and storage.

Recommended next integration

Use a provider that explicitly supplies fighter profiles, fight-by-fight statistics, historical results, and MMA moneylines. Keep API keys on a small server—not in a public mobile app. Provider options to evaluate:

  • FighterAPI data atlas — UFC fight stats, fighter history, ratings and partial odds coverage.
  • UFCalendar API docs — fighter stats, fight history, ratings and odds coverage.
  • Sportradar MMA API — commercial feeds including profiles, stats and win probabilities.

Confirm pricing, coverage, licensing, and permitted display/storage before choosing a provider.
